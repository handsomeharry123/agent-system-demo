# 项目目录说明

本项目按交付物类型划分为以下目录：

- `000.文档纪要`：项目说明、操作指南和过程纪要。
- `001.产品文档`：需求说明、产品方案、模板和示例材料。
- `002.前端代码`：医小知前端源码、静态资源、依赖及构建配置。
- `003.数据库脚本`：数据库初始化、迁移及数据脚本（当前暂无）。
- `004.后端代码`：服务端源码与配置（当前暂无）。
- `005.项目测试`：测试脚本、诊断工具、截图及测试产物。

前端启动方式：

```bash
cd 002.前端代码
npm run dev
```

前端构建方式：

```bash
cd 002.前端代码
npm run build
```
