## 3. 问题排查与修复

### DEF-IND-001：残缺数据库规则会以空内容返回

- 严重程度：中
- 现象：当 `risk_rules` JSON 损坏、缺少风险档位或缺少描述时，转换层能够容错，但接口可能返回空阈值/空说明，前端会静默展示残缺内容。
- 原因：接口仅转换数据库 JSON，未校验五维数量、维度唯一性以及规则字段完整性。
- 修复：增加响应前完整性校验，强制要求 5 个唯一维度且每个维度的 3 档规则均包含阈值和说明；不完整时由统一错误处理返回服务器错误，不再伪装为成功数据。
- 复测：正常配置 HTTP 200；异常 JSON 单元测试通过；完整后端回归通过。
