# 统一准入评测沙盒—指标列表测试计划 V1.0

## 1. 测试目标

验证指标列表后端符合《统一准入评测沙盒-需求说明文档 V1.9》，能够从 MySQL 正确、完整且安全地向既有前端页面提供五维指标体系与评分规则。本轮不修改前端页面。

## 2. 测试范围

- `GET /api/evaluation/indicators`
- `GET /api/evaluation/indicators/scoring-rules`
- `evl_dimension`、`evl_indicator` 表及 V1.9 幂等数据升级脚本
- 登录鉴权、`IT_ADMIN` 角色授权、响应数据契约、排序、风险规则、异常配置保护
- TypeScript 构建及现有后端测试回归

## 3. 测试环境

- 后端：`http://127.0.0.1:3000`
- 数据库：当前 `.env` 指向的开发 MySQL；测试只读取业务数据，鉴权测试产生的临时会话须精确清理
- 工具：Vitest、TypeScript、Node.js HTTP 客户端、mysql2

## 4. 准入标准

- 五个维度严格按输入、输出、行为、数据、工具安全排序
- 指标依次为 ASR、GCR、RR、PLR、RR，每项均有高/中/低三档阈值及非空说明
- 响应字段与既有前端 `DimensionMeta` 一致：`dimension`、`evalMethod`、`indicator`、`indicatorName`、`formula`、`rules`
- 未登录返回 401；非 `IT_ADMIN` 返回 403；`IT_ADMIN` 返回 200
- 数据库缺维度、重复维度或规则内容不完整时，不得返回看似成功的不完整数据
- SQL 连续执行两次后仍保持 5 个维度、5 个指标
- 类型检查、构建及全部非集成回归测试通过
