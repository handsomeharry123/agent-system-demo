# 测试工程文件说明

测试工程已分别放置在 `002.前端代码/tests` 和 `004.后端代码/tests`，不会改变业务源码。每个测试文件的职责、执行命令及报告路径详见：

- `002.前端代码/tests/README.md`
- `004.后端代码/tests/README.md`

统一报告根目录为 `005.项目测试/测试报告`：

```text
测试报告/
├── 前端/
│   ├── vitest/       JUnit 与 JSON 结果
│   ├── coverage/     HTML、LCOV 与 JSON 覆盖率
│   └── playwright/   E2E HTML、JUnit、截图、视频和 Trace
└── 后端/
    ├── vitest/       JUnit 与 JSON 结果
    ├── integration/  数据库集成测试结果
    └── coverage/     HTML、LCOV 与 JSON 覆盖率
```

报告目录由测试命令自动创建；`.gitkeep` 仅用于保留根目录。
