# 统一准入评测沙盒－数据集管理测试计划

## 1. 测试目标

验证 PRD V1.9 第二章数据集管理的后端接口、数据库业务规则、文件校验、权限与审计行为，并确认响应字段可直接支持既有前端页面。

## 2. 范围与环境

- 需求基线：`统一准入评测沙盒-需求说明文档V1.9.md`
- 后端：`http://localhost:3000/api/evaluation/datasets`
- 前端契约：`http://localhost:3002/app/evaluation/datasets`
- 数据库：本地 MySQL，仅创建带 `E2E-<时间戳>` 前缀的临时数据，测试结束精确清理。
- 文件：XLSX/CSV，单文件不超过 50MB。

## 4. 通过标准

- P0/P1 功能用例全部通过，无数据不一致或越权访问。
- TypeScript 类型检查、构建和已实现的自动化测试全部通过。
- 回归后不改变现有前端页面样式和字段。

## 5. 缺陷级别

- P0：数据丢失、越权、数据库不可恢复。
- P1：核心 CRUD/导入失败、事务不一致、前端契约不匹配。
- P2：边界校验、错误提示或排序问题。
- P3：不影响业务的文案与可维护性问题。
