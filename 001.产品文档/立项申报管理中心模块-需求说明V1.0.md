# 立项申报管理中心模块-需求说明

## 模块概述

**立项申报管理页**为立项申报的核心管理模块，覆盖「申报—暂存—提交—审核—结论」全流程。

其中 **1.1 为模块首页，采用 Tab（标签页）布局**：1.1 是默认展示的「全部立项」Tab，汇总全部项目；1.2–1.7 分别为按**立项状态**区分的 Tab 页（草稿 / 待审核 / 审核中 / 撤销修改 / 立项不通过 / 立项通过）。1.8–1.10 为由列表操作进入的二级页面（申报 / 详情 / 审核）。

共包含以下页面：

| 序号 | 页面 | 说明 |
| --- | --- | --- |
| 1.1 | 全部立项申报项目列表页 | 模块首页 默认「全部立项」Tab，汇总全部项目，按立项状态展示对应操作 |
| 1.2 | 草稿列表页 | 首页「草稿」状态 Tab 页，暂存但未提交的申报记录 |
| 1.3 | 待审核列表页 | 首页「待审核」状态 Tab 页，已提交待上级部门审核的记录 |
| 1.4 | 审核中列表页 | 首页「审核中」状态 Tab 页，上级部门审核中的记录 |
| 1.5 | 撤销修改列表页 | 首页「撤销修改」状态 Tab 页，申报人撤销后可修改的记录 |
| 1.6 | 立项不通过列表页 | 首页「立项不通过」状态 Tab 页，审核未通过的记录 |
| 1.7 | 立项通过列表页 | 首页「立项通过」状态 Tab 页，审核通过的记录 |
| 1.8 | 立项申报页 | 申报人填写/上传申报材料的表单页 |
| 1.9 | 立项信息详情页 | 只读查看申报信息 |
| 1.10 | 立项信息审核页 | 上级部门负责人审核并给出结论 |

## 1.1 全部立项申报项目列表页

**页面说明**：模块首页，默认展示的「全部立项」Tab 页；汇总展示全部立项申报项目，并根据每条记录的立项状态展示对应操作。

**字段与字段说明**

| 字段 | 字段说明 |
| --- | --- |
| 项目名称 | 取自用户填写完成的立项申报页填写的项目名称；支持模糊搜索、点击进入详情 |
| 申报科室 | 取自立项申报页选择的科室（科室代码+科室名称）；支持筛选 |
| 申报赛道 | 取自立项申报页选择项（字典生成）；支持下拉筛选 |
| 项目负责人 | 取自立项申报页填写的项目负责人 |
| 项目联系人 | 取自立项申报页填写的项目联系人 |
| 联系方式 | 取自立项申报页填写的联系方式；直接展示手机号，可对中间四位做掩码 |
| 希望获取的支持 | 取自立项申报页"希望获取的支持"字段 |
| 立项状态 | 系统根据流程节点自动展示；选项：草稿 / 待审核 / 审核中 / 撤销修改 / 立项不通过 / 立项通过 |

**图标/按钮与交互说明**（根据不同立项状态展示对应操作）

## 1.8 立项申报页

**页面说明**：申报人填写立项申报表单、上传申报材料的核心表单页，支持暂存与提交。

### 1.8.1 立项材料上传

| 字段 | 字段说明 |
| --- | --- |
| 项目申报书（必填） | 详见项目申报书模板文件 |
| 其他证明材料 | —— |
| 上传要求 | ①限定 PDF 版本；②支持多文件上传；③上传文件限制大小（单文件不超过 30M） |

**图标/按钮与交互说明**

| 图标/按钮 | 交互说明 |
| --- | --- |
| 模板下载 | 点击【模板下载】，下载 Word 版项目申报书模板 |
| 上传 | 点击【上传】：
· 上传成功，弹出"上传成功"弹窗
· 上传失败，弹出"上传失败，单文件超过最大限制30M"或"上传失败，仅支持PDF类型文件" |
| 暂存 | 点击【暂存】，弹出"注册表单填写记录已暂存至草稿状态列表页"弹窗 |
| 提交 | 点击【提交】：
· 提交成功，弹出"提交成功"弹窗，进入待审核状态列表页
· 提交失败，弹出"请检查立项申报表单信息是否填写完整"弹窗（备注：提交失败时，红色标注表单中未填写信息） |
