### 1. 用户列表页

**字段与字段说明**

| 字段 | 字段说明 |
| --- | --- |
| 筛选项 | 支持按照所属组织、用户角色、帐号状态进行筛选搜索 |
| 用户姓名 | 用户注册时填写 |
| 用户工号 | 用户注册时填写 |
| 所属组织 | 用户注册时选择 |
| 联系方式 | 用户注册时填写。格式校验：限制 11 个数字，失焦校验手机号格式，错误提示"请输入正确的 11 位手机号" |
| 用户角色 | 医院领导 / 信息科管理员 / 科室管理员 |
| 登录认证方式 | 密码认证 / 短信验证码认证 |
| 数据权限 | 医院领导：全院数据；信息科管理员：全院数据；科室管理员：本科室数据 |
| 帐号状态 | 正常 / 停用 |
| 账号创建时间 | YYYY-MM-DD HH:MM:SS |
| 最后登录时间 | YYYY-MM-DD HH:MM:SS |
| 行内操作 | 编辑 / 停用 / 恢复使用 |

**页面操作**

- 新增用户
- 批量启用
- 批量停用
- 导出列表

**交互说明**

- 点击【新增用户】，进入新增用户页
- 点击【批量启用】，用户列表中所有帐号状态均变为"正常"，所有账号均可正常使用
- 点击【批量停用】，用户列表中所有帐号状态均变为"停用"，所有账号均无法使用
- 点击【导出列表】，按照用户列表页已呈现信息导出 Excel
- 点击【编辑】，进入用户信息编辑页
- 点击【停用】，帐号状态变为"停用"，此账号无法使用
- 点击【恢复使用】，帐号状态变为"正常"，此账号恢复正常使用

## 三、系统各角色权限说明

系统当前包含 **医院领导、信息科管理员、科室管理员** 三种角色，其角色定位与数据权限如下：

| 角色 | 角色描述 | 数据权限 |
| --- | --- | --- |
| 医院领导 | 拥有全局数据查看权限，通常只读，不参与具体配置与用户管理 | 全院数据 |
| 信息科管理员 | 拥有平台全部功能与数据权限，可管理所有模块、用户与权限配置 | 全院数据 |
| 科室管理员 | 负责本科室智能体的接入申请与日常管理 | 本科室数据 |

### 3.1 医院领导（功能权限）

- 首页
- 医小管
- 统一台账中心
- 统一运行监控中心：监控告警总览页、业务监控页、状态监控页、成本监控页

### 3.2 信息科管理员（功能权限）

拥有平台全部功能模块权限，需注意以下限制：

- 注册管理待审核 tab 页：仅对信息科本科室注册的智能体可进行撤销操作
- 注册管理审核中 tab 页：仅对信息科本科室注册的智能体可进行撤销操作
- 资源申请管理·待审核 tab 页：仅对信息科本科室申请的资源可进行撤销操作
- 资源申请管理·审核中 tab 页：仅对信息科本科室申请的资源可进行撤销操作
- 告警事件处置·待处理告警事件页：仅对信息科本科室的智能体所产生的告警事件可进行处理操作
- 项目审计·待审计列表页：仅对信息科本科室申请的项目审计可进行撤销操作
- 项目审计·审计中列表页：仅对信息科本科室申请的项目审计可进行撤销操作

### 3.3 科室管理员（功能权限）

> 对于项目审计部分，仅立项申报项目的科室具备该权限。
> 
- 首页
- 医小管
- 智能体建设需求管理
- 智能体接入中心：注册管理列表页（撤销）、注册管理草稿 tab 页、注册管理待审核 tab 页（撤销）、注册管理审核中 tab 页（撤销）、注册管理撤销修改 tab 页、注册管理退回修改 tab 页、注册管理审核通过 tab 页、新建注册页、注册信息详情页
- 统一台账中心
- 医院资源管理中心·资源申请管理：全部列表页、草稿 tab 页、待审核 tab 页（撤销）、审核中 tab 页（撤销）、撤销修改 tab 页、退回修改 tab 页、审核通过 tab 页、申请权限页、权限申请详情页
