# 一、项目审计

## 1.1 项目审计页

**核心指标卡片**：日均服务患者人数增长率、医生采纳率、投入产出比、安全可控率。

> 注：核心指标卡片呈现的是根据所有智能体的数据计算权重；下方列表呈现的是单个智能体的数据。
> 

**筛选项**：支持按照申报科室、申报赛道筛选；支持日均服务患者人数、日均服务患者人数增长率、医生采纳率、异常故障次数、平均故障恢复时间、服务可用率、安全可控率按由高到低或由低到高排序。

**字段与字段说明**

**① 项目基本信息**

| 字段 | 字段说明 |
| --- | --- |
| 项目名称 | 取自用户填写的立项申报表单，文本只读展示 |
| 申报科室 | 取自用户填写的立项申报表单，文本只读展示 |
| 申报赛道 | 取自用户填写的立项申报表单，文本只读展示 |

**① 服务效率**

| 字段 | 字段说明 |
| --- | --- |
| 日均服务患者人数 | 取自业务监控页 |
| 日均服务患者人数增长率 | 增长率 =（应用后日均服务患者人数 − 应用前日均服务患者人数）÷ 应用前日均服务患者人数 × 100%；注：应用前日均服务患者人数需由医院提供 |

**② 服务质量**

| 字段 | 字段说明 |
| --- | --- |
| 任务执行成功率 | 取自业务监控页 |
| 响应时间 P99 | 取自业务监控页 |
| 医生采纳率 | 取自业务监控页 |
| 平均故障恢复时间 | 取自业务监控页 |
| 服务可用率 | 服务可用率 =（智能体上线总时长 − 异常故障次数 × 平均故障恢复时间）÷ 智能体上线总时长 × 100% |

**③ 服务效益**（原经济审计页内容合并）

| 字段 | 字段说明 |
| --- | --- |
| 投资金额 | 取自原立项申报表单（总投资 x 万元） |
| token 消耗量 | 取自统一运行监控中心的成本监控 |
| token 使用金额 | token 使用金额 = token 消耗量 × token 单位市场价 |
| 投入产出比 | 投入产出比 = 投资预算金额 / token 使用金额 × 100% |

**④ 服务安全**

| 字段 | 字段说明 |
| --- | --- |
| 风险行为拦截次数 | 风险行为拦截次数 = 异常输入攻击拦截次数 + 有害内容输出拦截次数 + 高风险请求拒绍次数 + 数据信息隐私泄露拦截次数 + 越权工具调用拦截次数 |
| 安全可控率 | 安全可控率 = 1 -（输入安全、输出安全、行为安全、数据安全、工具安全等维度安全性问题的拦截次数 ÷ 累计调用次数） |

**⑤ 附件材料**

| 字段 | 字段说明 |
| --- | --- |
| 附件材料 | 展示已上传审计材料的数量 |

**交互操作说明**

- **刷新**：点击后各维度数据更新到最新数据。
- **模板下载**：点击后将项目审计报告模板下载到本地。
- **批量导出**：点击后将选中的项目列表数据导出到本地，支持 Excel、CSV 格式。
- **上传材料 / 补充材料**（行内操作）：点击后跳转至项目审计材料上传页。
- **查看详情**（行内操作）：点击后进入项目审计详情页。

**字段与字段说明**

# 二、智能体行为审计

## 1.2 智能体行为审计页

**筛选项**：支持按照所属科室筛选；支持关键词模糊搜索；支持会话数按由高到低或由低到高排序。

**字段与字段说明**

| 字段 | 字段说明 |
| --- | --- |
| 智能体编号 | 取自智能体注册信息，格式“科室编号-准入顺序号”（如 0301-0007）；支持模糊搜索，点击可下钻至会话记录 |
| 智能体名称 | 取自注册表单填写的名称；支持模糊搜索 |
| 智能体版本 | 取自注册表单的当前版本号 |
| 所属科室 | 科室代码+科室名称；支持下拉筛选 |
| 会话数 | 该智能体累计会话数；支持按会话数排序 |
| 最近调用时间 | 最后一次产生交互/调用的时间；支持排序与时间范围筛选 |

**交互操作说明**

- **刷新**：点击后数据更新至最新时间。
- **批量导出**：点击后导出已选中的列表记录 Excel。
- **查看所有会话记录**（行内操作）：点击后进入智能体会话记录页。

### 1.2.1 智能体会话记录页

**筛选项**：支持关键词模糊搜索；支持会话时长按由高到低或由低到高排序；支持会话开始时间、会话结束时间按由近到远或由远到近排序。

**字段与字段说明**

| 字段 | 字段说明 |
| --- | --- |
| 会话标题 | 取首轮用户输入前 10 字自动生成（或系统摘要）；无标题时用“会话-开始时间”兜底；支持模糊搜索 |
| 首轮输入摘要 | 取自本次会话首条用户消息，截取前 30 字，超出显示“…”，悬浮查看完整；含隐私需脱敏 |
| 末轮输出摘要 | 取自本次会话末条智能体消息，截取前 30 字，超出显示“…”；含隐私需脱敏 |
| 会话时长 | = 会话结束时间 − 会话开始时间，格式化展示（如 1 分 48 秒）；支持排序 |
| 会话开始时间 | 本次会话首条消息的时间；支持排序与时间范围筛选；YYYY-MM-DD HH:MM:SS |
| 会话结束时间 | 本次会话末条消息的时间；支持排序与时间范围筛选；YYYY-MM-DD HH:MM:SS |

**交互操作说明**

- **刷新**：点击后数据更新至最新时间。
- **查看详情**（行内操作）：点击后展示该条会话全过程信息（真实会话页面）。

# 三、操作日志

## 1.3 操作日志页

**筛选项**：支持按照所属组织、操作模块、操作类型、操作结果筛选；支持按操作时间由近到远或由远到近排序。

**字段与字段说明**

| 字段 | 字段说明 |
| --- | --- |
| 用户名称 | 根据登录账号自动获取 |
| 用户角色 | 医院领导 / 信息科管理员 / 科室管理员 |
| 所属组织 | 取自用户注册时填写信息 |
| 操作模块 | 首页 → 审计中心 10 个模块 |
| 操作类型 | 新建/新增/立项申报/删除/启用/停用/禁用/上传/下载/导入/导出/审计/撤销/重新发起/分派/处理/编辑/查看/刷新/发起对话/智能化匹配/风险分级/注册资源/权限申请（各模块操作类型详见下表） |
| 操作描述 | 根据用户操作具体呈现（如“用户新建一条注册申请，暂存至草稿列表”）；截取前 30 字，超出显示“…”，悬浮查看完整 |
| 操作结果 | 成功 / 失败及失败原因 |
| 登录 IP 地址 | 根据用户登录 IP 自动记录 |
| 操作时间 | YYYY-MM-DD HH:MM:SS |

**交互操作说明**

- **刷新**：点击后数据更新至最新时间。
- **批量导出**：点击后导出已选中的列表记录 Excel。
- **查看详情**：点击后进入操作日志详情页。

### 1.3.1 操作日志详情页

**字段与字段说明**

| 字段 | 字段说明 |
| --- | --- |
| 用户名称 | 根据登录账号自动获取 |
| 用户角色 | 医院领导 / 信息科管理员 / 科室管理员 |
| 所属组织 | 取自用户注册时填写信息 |
| 操作模块 | 首页 → 审计中心 10 个模块 |
| 操作类型 | 同上（各模块操作类型详见下表） |
| 操作描述 | 根据用户操作具体呈现，完整呈现所有信息 |
| 操作结果 | 成功 / 失败及失败原因 |
| 登录 IP 地址 | 根据用户登录 IP 自动记录 |
| 操作时间 | YYYY-MM-DD HH:MM:SS |

**交互操作说明**

- **返回**：点击后返回到进入操作日志详情页的前一页。
