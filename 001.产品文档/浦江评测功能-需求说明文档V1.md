# 浦江评测功能-需求说明

<aside>
📌

**文档目的**：在现有评测中心「安全性评测」基础上，新增三方评测入口，补充「浦江评测（浦江实验室智能体评测）」模块，并通过智能辅助简化用户操作体验。本文按页面逐一说明字段、字段说明与页面交互，不做跨页面合并。

</aside>

## 一、背景与范围

### 1.1 背景

当前评测中心仅支持平台内置的「安全性评测」能力，缺少与外部权威评测平台的对接入口。为完善「立项—接入—安全评测—三方评测—纳管」闭环，需在评测中心新增三方评测入口，首批接入「浦江实验室智能体评测」，并通过智能辅助（字段自动带入、状态自动流转、结果自动解析呈现）降低用户填报与查阅成本。

### 1.2 功能范围

| 一级功能模块 | 二级功能模块 | 说明 |
| --- | --- | --- |
| 统一评测沙盒 | 1. 安全性评测 | 沿用现有 Demo 中全部内容，统一归入「安全性评测」模块，本次不做功能变更 |
| 统一评测沙盒 | 2. 浦江实验室评测 | 本次新增模块，含评测任务管理页（全部/草稿/评测中/评测通过/退回修改）、新建评测任务页、评测结果详情页 |

## 二、浦江实验室评测

### 2.1 评测任务管理页 · 全部列表页

**字段及字段说明**

| 字段 | 字段说明 |
| --- | --- |
| 筛选项 | 关键词搜索框；支持按照评测状态筛选 |
| 序号 | 系统自动生成，按提交时间倒序递增编号；支持翻页连续编号；1、2、3…… |
| 智能体编号 | 取自智能体注册信息详情页；科室编号-准入顺序号（如 0001） |
| 智能体名称 | 取自智能体注册信息详情页；点击名称跳转「智能体详情页」；超出 10 字省略处理，悬浮展示完整名称 |
| 智能体版本 | 取自智能体注册信息详情页填写的版本号；1.0 / 1.1 / 2.0 / 2.1 / …… |
| 评测平台 | 浦江实验室智能体评测 |
| 评测维度 | 临床任务规划与推理 / 医疗工具调用与执行 / 医疗场景感知与交互 / 记忆与上下文保持 / 医疗多智能体协作 |
| 评测状态 | 草稿 / 评测中 / 评测通过 / 退回修改 |

**图标 / 操作**：新建评测任务

**交互说明**

- 点击【新建评测任务】，进入新建评测任务页。
- 点击【查看详情】，进入评测结果详情页。
- 点击【编辑】，进入新建评测任务页（保留已编辑内容）。
- 点击【删除】，评测任务从当前列表中删除。
