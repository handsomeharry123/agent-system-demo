# 一、经济审计

## 1.1 经济审计页

**筛选项**：支持按照所属科室筛选；支持投资预算金额、token 消耗量、token 使用金额、投入产出比按由高到低或由低到高排序。

**字段与字段说明**

| 字段 | 字段说明 |
| --- | --- |
| 智能体编号 | 取自注册表单自动生成的编号；科室编号-准入顺序号（如 0001） |
| 智能体名称 | 取自已提交的注册表单；超出 10 字省略处理，悬浮展示完整名称 |
| 智能体版本 | 取自注册表单填写的版本号（1.0/1.1/2.0/2.1……） |
| 所属科室 | 取自原注册表单（科室代码+科室名称） |
| 投资预算金额 | 取自原注册表单（总投资 x 万元） |
| token 消耗量 | 取自统一运行监控中心的成本监控 |
| token 使用金额 | token 使用金额 = token 消耗量 × token 单位市场价 |
| 投入产出比 | 投入产出比 = token 使用金额 / 投资预算金额 × 100%（投资预算金额统一换算为元后计算） |
| 最后更新时间 | YYYY-MM-DD HH:MM:SS |

**交互操作说明**

- **刷新**：点击后数据更新至最新时间。
- **批量导出**：点击后导出已选中的列表记录 Excel。
